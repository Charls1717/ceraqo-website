# CERAQO — Q-ARMOR

Cinematic scroll site for Q-ARMOR: a scroll-scrubbed frame-sequence dive
(GSAP ScrollTrigger + Lenis + canvas), a conversion layer, and a
GitHub Pages deploy pipeline.

## Switching pre-order to the Shopify checkout

Every "Pre-order — €169" control (the floating pill and the button in
the Batch section) reads one value: `PREORDER_URL` in `src/config.ts`.

- Today it is empty, so the buttons fall back to the Batch 001
  email-reservation form.
- When the Shopify store is ready (product added, domain connected,
  payments enabled — configured directly in Shopify, not in this repo),
  paste the product/checkout URL into `src/config.ts` — or set
  `VITE_PREORDER_URL` at build time — and every control becomes a
  direct checkout link. That is the entire migration.

## Development

```bash
npm ci
npm run build
npm run preview   # http://localhost:4173
npx playwright test
```

Frame sequences are generated by `scripts/extract-frames.sh` from the
source clips in `bridge/out/`.
